Portfolio website

Website & run instructions

This portfolio is a static website made with HTML, CSS, and JavaScript. It has no package installation or build step.

Open the website

The website file in this project is:

website-cv.html

There is no public hosting address configured in this project. After deployment, use the public URL provided by your hosting service.

View the portfolio

Run it locally

  1. Open this project folder in VS Code.
  2. In the VS Code terminal, run python3 -m http.server 8000.
  3. Open http://localhost:8000/ in your browser. The home page will take you straight to the portfolio.
  4. To stop the local server, return to the terminal and press Ctrl+C.

If Python is unavailable, open website-cv.html directly in your browser, or use the VS Code Live Server extension.
